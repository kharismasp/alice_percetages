WONDERLAND PERCENT MISSION · GRADE 6 · v5

How to run
1. Open this whole folder in VS Code.
2. Open index.html.
3. Run with Live Server, or open index.html directly in a browser.

Learning flow
Chapter 2 / Core Percentage Mission
1. Fraction · Decimal · Percent matching — 2 problems
2. Percent means per 100 — 2 problems
3. Fraction → percentage — 3 problems
4. Decimal → percentage — 2 problems
5. Percentage of an amount — 3 problems; teaches OF = ×
6. Discount story — 1 problem
7. Part/whole → percentage story — 1 problem
8. Remaining amount story — 1 problem

Chapter 3 / Mystery Trail — gentle advanced story practice
9. Percentage of an amount in context
10. Fraction → percentage in context
11. Decimal filled → percentage remaining
12. Two-step discount + budget
13. Reverse percentage using friendly 20%, 25%, or 50% chunks

Scaffolding
- Only one scene/quest is visible at a time; later quests stay locked.
- Problems and story numbers randomize.
- Hints guide interpretation first rather than immediately giving the calculation.
- Every problem has a 3-wrong rescue: after 3 incorrect attempts, a worked explanation and answer appear so the learner can continue.
- Story problems have supporting visuals/animations.
- Final outro praises persistence and problem-solving, not just speed or correctness.
